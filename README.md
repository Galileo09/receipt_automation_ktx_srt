# 🚄 KTX & SRT 영수증 자동화

**"코딩은 모르지만, 불편함은 참을 수 없었습니다."**

이 프로젝트는 개발 지식이 전혀 없는 비개발자가 100% **AI와의 대화(Vibe Coding)**를 통해 완성한 **코레일 및 SRT 영수증 자동 다운로드 도구**입니다. 매달 증빙을 위해 하나하나 영수증을 클릭하고 저장해야 했던 번거로움을 해결하기 위해 만들었습니다.

---

## 🌟 제작 배경

* **주체:** 프로그래밍 언어를 한 줄도 모르는 비개발자
* **방법:** AI(Claude/Gemini)와 대화하며 코드를 짜고 오류를 수정하는 '바이브 코딩' 방식
* **목표:** 날짜만 입력하면 알아서 영수증을 싹 긁어오는 자동화 도구 구현

---

## 🛠 주요 기능

* **KTX(코레일) 영수증 자동 저장** — 기간 내 인쇄완료 영수증을 이미지 파일로 자동 저장
* **SRT 영수증 자동 저장** — 기간 내 영수증을 이미지 파일로 자동 저장
* **Gmail 자동 발송** — 저장된 영수증을 지정한 이메일로 자동 전송
* **웹 대시보드** — 브라우저에서 날짜만 입력하면 끝. 별도 프로그램 설치 불필요

---

## 🚀 설치 및 실행 방법

> ⚠️ 딱 두 가지만 설치하면 됩니다: **Python**과 이 **프로그램 파일들**

---

### 1단계 — Python 설치

Python은 이 프로그램을 돌리는 엔진입니다. 한 번만 설치하면 됩니다.

1. 아래 주소를 복사해서 브라우저 주소창에 붙여넣고 이동하세요.
   ```
   https://www.python.org/downloads/
   ```
2. 노란색 **"Download Python 3.12.x"** 버튼을 클릭해서 설치 파일을 받습니다.
3. 받은 파일을 실행(더블클릭)합니다.
4. 설치 화면 맨 아래에 **"Add Python to PATH"** 체크박스가 있습니다. **반드시 체크**한 뒤 Install Now를 누릅니다.

   ![PATH 체크 예시 - 꼭 체크하세요!]

5. 설치가 끝나면 Close를 누릅니다.

---

### 2단계 — 프로그램 파일 받기

**방법 A — 초보자 추천: ZIP으로 받기**

1. 이 GitHub 페이지에서 초록색 **"Code"** 버튼을 클릭합니다.
2. **"Download ZIP"** 을 클릭해서 파일을 받습니다.
3. 받은 ZIP 파일을 **바탕화면**에 압축 해제합니다.
   - 파일 우클릭 → "모두 압축 풀기" → 압축 풀 위치를 바탕화면으로 지정

**방법 B — Git이 설치된 경우**

```
git clone https://github.com/Galileo09/myPublicRepository
```

---

### 3단계 — 프로그램 실행

1. 압축을 푼 폴더 안의 `receipt_train` 폴더로 이동합니다.
2. **`run_server.bat`** 파일을 **더블클릭**합니다.

   > 처음 실행할 때는 필요한 파일들을 자동으로 설치하므로 **1~3분 정도** 걸릴 수 있습니다. 검은 창(CMD)이 열려서 글자가 지나가는 것이 정상입니다.

3. 설치가 끝나면 자동으로 브라우저가 열리고 대시보드가 나타납니다.
   - 브라우저가 자동으로 열리지 않으면 브라우저 주소창에 아래를 입력하세요.
     ```
     http://localhost:8000
     ```

4. **프로그램을 종료**하려면 검은 창(CMD)에서 `Ctrl + C` 를 누르거나 창을 닫으면 됩니다.

## 📖 사용 방법

### Gmail 연동 (처음 한 번만)

영수증을 이메일로 자동 발송하려면 Gmail 연동이 필요합니다.

1. 대시보드 하단 **"Gmail 발송 설정"** 카드에서 **수신자 이메일**을 입력하고 **💾 저장**을 누릅니다.
2. **🔑 Gmail 로그인** 버튼을 누릅니다.
3. 브라우저 창이 열리면 Gmail에 로그인합니다. 받은편지함까지 이동하면 창이 자동으로 닫힙니다.
4. 이후부터는 로그인 없이 자동 발송됩니다.

---

### 영수증 자동화 실행

1. **KTX** 또는 **SRT** 카드에서 날짜를 선택합니다.
   - 시작일 / 종료일: 영수증을 받을 기간

2. **저장 경로**를 확인합니다. 기본값은 `바탕화면\출장복명` 폴더입니다.
   - 변경하려면 경로를 직접 수정하거나 **📁 찾기** 버튼을 눌러 폴더 경로를 붙여넣습니다.

3. **"완료 후 자동으로 메일 발송"** 체크박스를 원하는 대로 설정합니다.

4. **▶ 시작** 버튼을 누릅니다.

5. 화면 하단에 진행 단계가 표시됩니다:
   ```
   시작 → 로그인 → 캡처 → 메일 → 완료
   ```
   - **KTX:** 브라우저 창이 열리면 코레일 아이디/비밀번호로 수동 로그인합니다. 로그인 후 나머지는 자동으로 진행됩니다.
   - **SRT:** 로그인까지 자동으로 진행됩니다.

6. **완료** 단계가 되면 지정한 폴더에 영수증 이미지 파일이 저장됩니다.

## ❓ 자주 묻는 문제

**Q. `run_server.bat`를 더블클릭해도 아무것도 안 열려요**

→ Python 설치 시 **"Add Python to PATH"** 를 체크하지 않았을 가능성이 높습니다. Python을 다시 설치하면서 해당 옵션을 체크해주세요.

**Q. 브라우저에서 "사이트에 연결할 수 없음"이 뜨는데요**

→ 검은 창(CMD)이 열려 있는지 확인하세요. 창이 닫혀 있으면 서버가 종료된 것입니다. `run_server.bat`을 다시 실행하세요.

**Q. Windows에서 "Windows가 PC를 보호했습니다"는 경고가 떠요**

→ 직접 만든 프로그램이라 인증서가 없어서 나타나는 경고입니다. **"추가 정보"** 를 클릭한 뒤 **"실행"** 을 누르면 됩니다.
